# Credit Card Transaction and Customer Analytics

## 📌 Project Overview

This project analyzes credit card transaction and customer data to understand transaction performance, customer behavior, payment preferences, and transaction success rates.

The project uses Python, SQL, Excel, and Power BI to clean, analyze, and visualize the data and convert raw data into meaningful business insights.

## 🎯 Project Objectives

- Analyze credit card transaction performance
- Understand customer behavior and spending patterns
- Identify transaction success and failure rates
- Analyze payment methods and transaction categories
- Compare transaction performance across cities and categories
- Build an interactive dashboard for business insights

## 🛠️ Tools & Technologies

- **Python** – Data cleaning and exploratory data analysis
- **Pandas & NumPy** – Data manipulation and analysis
- **SQL** – Data querying and business analysis
- **Excel** – Data cleaning and preparation
- **Power BI** – Interactive dashboard and visualization

## 📊 Dataset

The dataset contains credit card transaction and customer information.

- 30,000+ transactions
- 2,000+ customers
- Transaction amount
- Transaction status
- Payment method
- Transaction category
- Customer details
- City information

## 📈 Key Insights

- Total transaction value analyzed: approximately ₹2.36 crore
- More than 30K transactions were analyzed
- More than 2K customers were included
- Overall transaction success rate was approximately 71%
- Customer payment preferences and transaction patterns were analyzed
- Transaction performance was compared across different categories and locations

## 💡 Project Outcome

The project helped transform raw credit card transaction data into an interactive dashboard and meaningful business insights. These insights can help businesses understand customer behavior, monitor transaction performance, and identify areas that may require improvement.
